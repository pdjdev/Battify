## 主要功能

- 可在任务栏查看的电池百分比图标
- 充电状态变化时显示通知弹窗
- 匹配 Windows 10 和 11 浅色及深色主题的样式
- 支持 HiDPI

## 系统要求

- Windows 10 或更高版本
- Windows 10 和 11 中已包含的 .NET Framework 4.8
